## Architecture Policy

The V1 architecture is officially frozen.

During implementation it is **not allowed** to:

- create undocumented modules;
- modify documented responsibilities;
- introduce undocumented architectural layers;
- redesign workflows;
- change component boundaries;
- introduce undocumented communication patterns.

Any architectural evolution must be proposed for a future V2.
